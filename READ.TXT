Problem 4: Financial Transaction Analysis
Problem Statement
javaclass Transaction {
    private String transactionId;
    private String accountId;
    private TransactionType type; // DEBIT, CREDIT
    private double amount;
    private String category; // GROCERY, ENTERTAINMENT, UTILITY, etc.
    private LocalDateTime timestamp;
    private String merchantId;
    private String location;
}

class Account {
    private String accountId;
    private String customerId;
    private AccountType type; // SAVINGS, CHECKING, CREDIT
    private double balance;
}
Tasks
4.1 Fraud Detection: Find accounts with suspicious patterns:

More than 5 transactions in different cities within 1 hour
Total debit amount > 3× their average daily spending in the last 30 days
More than 3 transactions declined (you'll need to add this field) followed by a successful large transaction

4.2 Spending Analysis: For each customer, create a monthly spending breakdown showing:

Top 3 spending categories
Month-over-month growth rate for each category
Percentage of income spent (assuming credits are income)
Unusual spending patterns (>2 standard deviations from their average)

4.3 Merchant Insights: Find merchants that:

Have increasing transaction volume (each month higher than previous) for 3+ consecutive months
Average transaction amount is in the top 10% of their category
Have customers from at least 5 different locations
Have a repeat customer rate > 40% (customers who transact more than once)

4.4 Cash Flow Forecast: For each account, predict the next month's balance by:

Calculating average monthly credits and debits for the last 6 months
Identifying recurring transactions (same merchant, similar amount, regular intervals)
Adjusting for seasonal patterns (compare to same month last year if available)

4.5 Network Effect: Find groups of accounts that frequently transact with the same merchants within 24 hours of each other, suggesting they might be related (family, colleagues, etc.). Minimum group size: 3 accounts, minimum co-occurrence: 5 times.

Problem 5: Academic Performance Analysis
Problem Statement
javaclass Student {
    private String studentId;
    private String name;
    private String major;
    private int year; // 1, 2, 3, 4
    private List<Course> courses;
}

class Course {
    private String courseId;
    private String courseName;
    private String department;
    private int credits;
    private String professor;
    private List<Assessment> assessments;
}

class Assessment {
    private String type; // QUIZ, MIDTERM, FINAL, PROJECT
    private double score; // 0-100
    private double weight; // 0-1
    private LocalDate date;
}
Tasks
5.1 Difficulty Analysis: For each course, calculate:

Average final grade
Standard deviation
Fail rate (grade < 60)
Grade distribution across A, B, C, D, F
Identify the 10 "hardest" courses based on a weighted formula considering all factors.

5.2 At-Risk Student Detection: Find students who:

Have a GPA < 2.5 in current semester
Are taking courses where 60%+ of their current assessment scores are below 70
Have shown a declining trend (each semester's GPA lower than previous)
Are not in their first year (first-year struggles are normal)

5.3 Professor Performance: For each professor, analyze:

Average student performance across all their courses
Consistency (standard deviation of average grades across different course sections)
Student improvement rate (compare quiz → midterm → final progressions)
Department ranking (compared to other professors in same department)

5.4 Course Recommendation: For a given student, recommend 5 courses for next semester based on:

Courses typically taken by students with similar majors and current GPA
Prerequisites completed
Professor ratings (based on student performance)
Schedule conflicts (courses offered at same time)
Difficulty balance (don't recommend all hard courses)

5.5 Cohort Analysis: Group students by major and year, then for each cohort:

Track GPA progression from year 1 to current year
Identify which courses have the biggest impact on GPA (correlation analysis)
Find "make-or-break" courses where performance strongly predicts graduation success
Calculate retention rate and identify patterns in students who drop out
